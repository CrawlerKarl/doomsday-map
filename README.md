# What to watch before Avengers: Doomsday

A zoomable timeline of every Marvel film and series, with *Avengers: Doomsday* (December 18, 2026)
as the focal point. Titles are tiered by how much they matter going in — must watch, worth
watching, only if curious, everything else — with a one-line "why it matters", where each one
streams (United States), and a prep list. Mark what you've seen and star what you want to watch
first; your marks stay in your own browser.

Live: https://crawlerkarl.github.io/doomsday-map/

Built from a personal watch tracker; the map is one fan's judgement based on the confirmed cast
and the storylines Marvel has announced. The film's plot is not public.

Film and series data and images come from [TMDB](https://www.themoviedb.org). This product uses
the TMDB API but is not endorsed or certified by TMDB. Streaming availability via JustWatch
through TMDB.
